`figures/` contains the individual panels, `tables/` their supporting measurements,
and `sources/` the supplied language map, phonological-feature heatmap and map code.
The automatic alignments estimate intended-phone intervals; they do not provide
listener error labels or verified actual pronunciations. The heatmap's original
numerical scoring procedure remains to be documented.
