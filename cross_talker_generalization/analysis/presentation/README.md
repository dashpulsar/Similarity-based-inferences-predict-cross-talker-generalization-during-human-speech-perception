The figure manifests record panel sources and page ordering. These collections
contain retained analyses, not newly fitted models. Historical z statistics,
held-out likelihoods and automatic phone measurements retain their distinct
interpretations; see the [scientific specification](../../docs/SCIENTIFIC_SPEC.md).

Rebuild the complete collection with
`python cross_talker_generalization/scripts/build_figures_only_package.py`.
Rebuild the concise collection with
`python cross_talker_generalization/scripts/build_concise_figure_package.py`.
