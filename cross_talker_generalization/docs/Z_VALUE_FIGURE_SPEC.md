# Z-value figure specification

This file defines the main **SBI result display** requested on September 6: layerwise z, three-fold intervals, and a normalized behavioral ceiling. It does not designate manuscript main figures or replace Figures 1/2. Similar HVE panels respond to the earlier request for complete variability displays. It changes presentation, not previously fitted models. See the [requirements review](FLORIAN_REQUIREMENTS_REVIEW.md) for meeting evidence and the [generated review](../analysis_update_2026-09-06/z_value_review/README.md) for the actual outputs.

## 1. Quantity on the y-axis

For each representation/layer and each of three participant folds, store the signed Wald statistic of the theoretical predictor:

```text
z_f = beta_f / SE(beta_f)
c_bar = mean(c_1, c_2, c_3)
normalized_z_f = 100 * z_f / c_bar
```

`c_f` must be a behavioral-ceiling **z**, not ceiling accuracy or a log-loss gain. Label the normalized axis `Predictor z / mean ceiling z (%)`; also export a raw `Predictor Wald z` version. Do not call either axis variance explained, predictive accuracy, or percent of human behavior captured. Preserve the sign and allow values below zero and above 100%. If the mean ceiling is nonpositive or nonfinite, do not normalize.

## 2. Fold uncertainty and reference lines

Resample the three observed fold values with replacement, average each resample, and take the 2.5th and 97.5th percentiles. For three folds there are only 27 ordered bootstrap resamples, so enumerate them exactly rather than introducing an unnecessary random seed. Show the three original points, mean, and interval.

- Ceiling mean: black dashed horizontal line at 100%.
- Ceiling band: apply the same bootstrap to `(c_1, c_2, c_3)`, then divide both interval limits by `c_bar` and multiply by 100; gray shading. It need not be exactly symmetric around 100.
- Nominal two-sided Wald references: `+1.96 * 100 / c_bar` and `-1.96 * 100 / c_bar`, orange dotted lines with an explicit legend. On raw-z plots these are simply +/-1.96.
- Zero: thin solid line, not a significance line.

These are nominal per-coefficient z references, **not** a significance test of the mean across folds or a correction for testing many layers/methods. The normalized predictor interval holds the denominator at the mean ceiling; it is not a joint uncertainty interval for the ratio. Three-fold bootstrap intervals are descriptive and limited; overlapping two-fold training fits are dependent. Participant-bootstrap predictive intervals can remain in companion analyses, but must not be described as the requested fold bootstrap.

## 3. X-axis and visual grammar

For SBI: MFCC (39-D), STRF (24-D), blank gap, CNN-2–6, Tr-0, even Tr-2–24. Draw baselines as discrete points, not unlabeled horizontal lines; do not join them to the network trajectory. Use one panel per dataset and HuBERT variant. HVE panels use the same layer labels and one named measure per panel, with base/ASR-FT distinguished consistently. Acoustic HVE baselines are not available merely because acoustic SBI was run; do not invent them.

Show every supported HVE definition, with explicit unavailable cells or a coverage table. Use separate B23 strata for measures calculated on different participant sets. All-layer summaries must say “18 registered feature spaces,” not “all 32 layers.” Provide PNG, SVG, fold data, summary data and an index.

## 4. Which fits provide the z values?

This must be recorded per source, because the current repository contains different procedures:

| Source | What the z describes | Can it use the old ceiling? |
|---|---|---|
| Stored notebook `z_test` | GLMM re-estimated on each held-out fold; descriptive association | Only as the explicitly labeled historical normalization; a present-day matched-row/formula audit is still needed |
| Revised `cv_train` coefficient | Predictor-only GLMM fit to two folds | No: the old ceiling was fitted on one held-out fold |
| Frozen-model held-out likelihood | Predictive score on unseen participants | No coefficient z is generated by scoring alone |

The review exports the first as a **historical format reference** and the second as **revised-definition training-fold z**, without mixing them. No new GLMM is fitted by the review plotting script.

For the next current-definition normalized rerun, the notebook-style option is explicit: construct the theoretical predictor without using test responses, fit the association GLMM separately on each test fold to extract z, and do the same for an item-by-condition ceiling built from the other two folds. Use the same analyzed rows, binomial responses, blocking/random structure, and convergence rules within each comparison; label it `test-fold refit association`. Keep existing frozen-model prediction as a separate analysis. This is a new association analysis, not the genuine CV procedure requested earlier; it is not silently enabled by changing a plot label.

Alternatively, retain training-fit z throughout and construct a correspondingly training-scope ceiling with an explicitly specified response-splitting procedure. Do not choose a construction just to produce a high or low normalized curve. The scope needs to be agreed before a new normalized analysis is described as the final method.

## 5. Optimization, condition comparisons and manuscript placement

The theoretical-predictor-only model is the optimization model; condition must not be included in that search. The actual code may also contain design blocking terms such as test talker. Record those terms rather than describing every implementation as literally having only one fixed term.

The September email requests both likelihood and z objectives and both reporting metrics. Z-first figures do not delete that requirement. Use the same samples within each search and keep categorical layer choice distinct from continuous parameter fitting. Fold-specific candidate selection for independent prediction belongs inside training data.

The paper can retain Tr-24 as the common main representation, as requested in the meeting, while the review prominently shows layer trajectories. Report the two condition comparisons with their actual statistics; a multi-level condition term has no single coefficient z equivalent to its omnibus likelihood-ratio test.
